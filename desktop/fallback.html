Đang kết nối đến Giày Đẹp Store

Ứng dụng Desktop đang kết nối với máy chủ web tại địa chỉ http://localhost:5173. Nếu quá trình này mất nhiều thời gian, vui lòng kiểm tra trạng thái máy chủ.

Hướng dẫn khởi động máy chủ:
  1. Mở Terminal hoặc Command Prompt tại thư mục gốc của dự án.
  2. Di chuyển vào thư mục frontend: cd frontend
  3. Chạy lệnh khởi động: npm run dev
